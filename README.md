# Mere Anju — Shubh Deepavali 🪔

Personal Diwali experience for Malik, designed with a warm white, pink and gold maximalist theme. All artwork is locally maintained in `assets/`.

Open `index.html` in any modern browser. Replace personal-photo URLs in `config.js` with your own direct image links. The full interactive gallery, diya intro, lightbox, wishes, flip cards, terminal and fireworks are provided in this repository.

See GitHub Pages deployment notes below after the source is committed.
