# Mere Anju — Diwali for Malik 🪔✨

White/pink/gold maximalist Diwali greeting website. Entirely static and mobile-first; no backend, cookies or analytics.

## Open
Visit `index.html`. After GitHub Pages is enabled, site URL is `https://bjendermisra-ops.github.io/mere-anju/`.

## Replace Malik's photos
Change only the `hero` and `photos[].src` URLs inside `config.js`. Direct, publicly reachable HTTPS image links work best; the original example.com links are deliberately retained for you to replace. Failed images render a designed fallback instead of a broken-image icon.

## Artwork
40 bespoke SVG illustrations in `assets/`; 4 floral corners, 4 lanterns, 5 diyas, 3 gifts, 2 sweets, 2 arches, 3 rangolis, 4 mandalas, 3 torans, 4 paisleys, 2 hearts, 2 photo frames, 2 sparkle fields. These are lightweight editable vectors, not copies of anyone's photograph.

## Features
Intro diya, rangoli bloom, falling petals, skip/open transition, animated marquees, hero tilt, terminal typing, 3D swipe ring, photo lightbox with zoom and thumbnails, flip cards, playful heat meter, five diya wishes, fireworks, cursor stars, scroll progress, responsive layout, reduced-motion support and keyboard controls.

## Deploy
Go to GitHub repository Settings → Pages → Source: Deploy from a branch → main → / (root), then Save. Site will use the URL above when Pages becomes active. This may require manual repository settings access.
